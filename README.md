# Tanstack Start Template

## To start the dev server

Step 1

```bash
pnpm i
```

Step 2 - Create a `.env` file and add all the required keys from `.env.example`

Step 3 -

```bash
pnpm db:migrate
```

Step 4 -

```bash
pnpm dev
```

## Setup involves

- Framework - Tanstack start
- Database - PostgreSQL
- DB ORM - Drizzle
- Authentication - Better auth
- UI - TailwindCSS + Shadcn
- Shadcn - Base UI, Nova, Tabler icons, Neutral theme, Button pointer enabled
- Others - Zod, React hook forms, Eslint, Prettier
